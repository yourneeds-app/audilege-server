## Deutsch

Audilege Server 0.4.0 verbindet die persönliche Hörbuch-, Podcast- und EPUB-Bibliothek mit dem Browser und der Audilege-App. Die Startseite zeigt angefangene Titel und kurze Regale. Die Suche umfasst Titel, Autoren, Reihen, Genres und Podcasts.

Lesen und Mitlesen verwenden eine zentrierte Buchseite. Über **Aa** lassen sich Schrift und Seitendarstellung anpassen. Hinzu kommen Lesezeichen, Buchsuche, Warteschlange und Kapitelende-Timer. Bei einer unterbrochenen Verbindung merkt sich der Browser ausstehende Positionsänderungen.

Admins können einen Medienordner wählen, abgeschlossene Mitlesefassungen exportieren, Originale wiederherstellen und Sicherungen mit Prüfsummen anlegen. Optional sind Passwortwiederherstellung per bestätigter E-Mail und Bibliotheksprüfungen mit einem gewählten KI-Modell. Jede KI-Änderung wird einzeln geprüft.

**Installation:** Das Archiv für dein System vollständig entpacken und unter Windows **Start-Audilege.cmd** oder unter Linux **sh start.sh** starten. Für ein Update den Server beenden und das neue Paket mit demselben Datenordner starten.

## English

This release brings a focused home page, catalogue-wide search, series and genre browsing, separate book and audiobook covers, a centered reader, synchronized bookmarks and offline position recovery. Administrators can review optional AI suggestions, configure email recovery and manage completed read-along editions and backups.

Extract the full archive, then run **Start-Audilege.cmd** on Windows or **sh start.sh** on Linux. When upgrading, stop the previous version and use the same data directory. SHA-256 checksums cover both downloads.
